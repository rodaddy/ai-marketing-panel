# Start Here

1. Unzip this complete folder.
2. Open or upload the folder in the AI agent you want to use.
3. Say:

> Read `INSTALL.md` and install this kit.

The agent will inspect its environment, install only the requirements declared
in `kit.json`, verify the strongest mode it can support, and tell you what to do
next. You do not need to install or understand programming tools yourself.

For internal dogfooding, first duplicate this entire kit into
`pocs/<use-case>/_working/`. Customer work uses an equivalent owned destination.
Never point a live panel at this PoC.

After installation:

- say “build a customer panel” to research and create 5-15 seats;
- say “wash this artifact” to run a completed panel;
- say “rewrite and retest” to create and compare three revisions;
- say “calibrate the panel” after real outcomes arrive.

The first useful result is not a generic demo. It is a validated panel workspace
with complete dossiers and a clearly defined real-world decision.
