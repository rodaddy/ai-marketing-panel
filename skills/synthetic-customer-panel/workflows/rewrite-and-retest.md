# Rewrite and Retest

Start from a completed, validated run. Read
`references/synthesis-and-scoring.md` and `references/safety-and-honesty.md`.

## 1. Diagnose before rewriting

Separate:

- changes supported by multiple core-fit seats;
- high-consequence objections from one credible seat;
- wrong-fit reactions that should not be optimized for;
- specialist gates that must be fixed;
- unknowns that require real evidence rather than better wording.

## 2. Create three distinct variants

Write three materially different versions, not synonym swaps:

1. the smallest correction to the original;
2. a different framing built around the strongest customer pain or goal;
3. a different proof, structure, or call-to-action strategy.

Preserve truthful claims, accessibility, and declared gates. Use owner voice
only here, and do not over-amplify stylistic quirks.

## 3. Retest cleanly

Prepare a fresh run for each variant. Use the same panel snapshot, scoring
weights, execution mode, and artifact conditions so comparisons are meaningful.
Do not show seats the prior verdict or tell them which version should win.

## 4. Compare

Report score movement, changed decisions by core-fit seat, wrong-fit behavior,
remaining objections, and whether confidence improved. Prefer a version because
the evidence improved, not merely because its numeric score is larger.

Stop after three unsuccessful rewrite cycles. Recommend customer interviews,
offer changes, or a better evidence source rather than optimizing indefinitely
against a fixed synthetic judge.
