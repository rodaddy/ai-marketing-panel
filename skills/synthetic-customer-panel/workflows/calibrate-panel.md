# Calibrate a Panel

Read `references/calibration-standard.md` completely.

## 1. Match the real outcome

Locate the completed run and the predeclared outcome measure and horizon. Do not
substitute a convenient vanity metric after the fact.

## 2. Append, never rewrite

Add one row to `calibration/CALIBRATION.md` containing the run ID, predicted
decision, score, actual outcome, segment if known, elapsed horizon, and notes.
Leave the run packet and panel snapshot unchanged.

## 3. Diagnose error

Classify a miss as one or more of:

- roster gap;
- stale or weak dossier evidence;
- seat homogeneity;
- synthesis error;
- scoring-weight error;
- distribution or execution factor outside the panel;
- outcome too early or too noisy to judge.

Do not blame a dossier merely because reality disagreed.

## 4. Tune conservatively

Do not change weights from a single result. After enough comparable outcomes,
propose the smallest evidence-backed adjustment and record the reason. Preserve
the old manifest with the runs it governed.

Report calibration as observed history, never as a universal accuracy claim.
