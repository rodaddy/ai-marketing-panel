# workflows/

The step-by-step procedures the skill dispatches: `build-panel.md`,
`wash-artifact.md`, `rewrite-and-retest.md`, `calibrate-panel.md`,
`maintain-panel.md`, and `room-lifecycle.md`.

Each maps to an operator phrase in `OPERATIONS-MANUAL.md`. `build-panel.md`
section 0 carries the wording the kit uses when it refuses to build on missing
evidence or a decision that cannot be proven right or wrong.
